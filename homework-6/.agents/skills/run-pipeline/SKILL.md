# Run the pipeline

1. Work from the `homework-6` directory and confirm `sample-transactions.json` exists.
2. Run `python orchestrator.py`.
3. Read `shared/results/summary.json` and confirm one result per input transaction.
4. Report total and status counts, followed by rejected IDs and validation reasons.
5. Do not output source accounts, destination accounts, names, or descriptions.
